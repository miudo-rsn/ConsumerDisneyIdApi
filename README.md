# consumer-disney-api-id-net-console

Aplicação console em C# (.NET) que consome a Disney API e mostra na tela os dados de um personagem.

Endpoint usado: https://api.disneyapi.dev/character/423

## Como rodar

```
cd ConsumerDisneyIdApi
dotnet run
```

## Resultado esperado

```
Nome:
Big Bad Wolf
Imagem:
https://static.wikia.nocookie.net/disney/images/7/73/The_Big_Bad_Wolf.png
```
